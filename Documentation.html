Universal Union Logistics Script Installation

A simple, step-by-step guide to get you up and running.

Welcome! 🎉

Thank you for choosing Universal Union Logistics! This guide will walk you through the installation process. It's designed to be super easy, especially for cPanel users. Don't worry, you can do this!

Before You Start

  • A web hosting account (like Bluehost, Namecheap, etc.) with **cPanel** access.
  • Your website domain name (e.g., `www.yourcargosite.com`).
  • The script files you downloaded, in a `.zip` format.
  • PHP version **7.4** or higher on your hosting. You can usually check or change this in your cPanel under "MultiPHP Manager" or "Select PHP Version".
1

Upload Your Files

First, log in to your cPanel. Look for the **File Manager**. Navigate to the `public_html` directory (this is your main website folder). Click "Upload", select your script's `.zip` file, and upload it. Once uploaded, right-click the `.zip` file and choose "Extract".

2

Create a Database

In cPanel, find **MySQL® Database Wizard**. Follow the steps:

  1. **Create a Database:** Give your database a name (e.g., `universal_union_db`).
  2. **Create a User:** Create a database user and a strong password. **Important: Save these details in a notepad!** You'll need them soon.
  3. **Add User to Database:** Assign the user to the database and give it **"All Privileges"**.
3

Import the SQL File

Now, find **phpMyAdmin** in cPanel. On the left, click on the database you just created. Then, click the **"Import"** tab at the top. Choose the `database.sql` file from the script files on your computer and click "Go". This will set up all the necessary tables.

4

Connect to Your Database

Go back to the **File Manager**. Find the file named `db.php`. Right-click it and choose "Edit". You need to replace the placeholder details with the database name, username, and password you saved in Step 2.

<?php
$con = mysqli_connect(
"localhost",
"your_database_user", // ← Replace this
"your_password", // ← Replace this
"your_database_name" // ← Replace this
);
?>
5

Set Up Email Notifications (Optional)

To send emails for shipment updates, you need to edit the `functions.php` file. Open it and find the `sendMail` function. You will need to add your own SMTP details from your email provider (like Gmail, SendGrid, or your hosting's email service).

function sendMail($to, $subject, $body) {
// ... a lot of code here ...
$mail->Host = 'smtp.example.com'; // ← Your SMTP host
$mail->Username = 'user@example.com'; // ← Your SMTP username
$mail->Password = 'your_password'; // ← Your SMTP password
// ... more code ...
}
6

You're All Set!

Congratulations! The installation is complete. You can now visit your website and access the admin panel by going to `www.yourcargosite.com/admin/login.php`.
